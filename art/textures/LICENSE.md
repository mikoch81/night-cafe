# Texture sources

All textures in this folder come from [ambientCG](https://ambientcg.com) and are released under
**CC0 1.0 Universal** (public domain) - https://docs.ambientcg.com/license/

They are inputs for the Blender shell render (`tools/shell_render.py`) only; nothing here is loaded
by Unity directly. Each folder keeps the 1K JPG Color / NormalGL / Roughness maps (plus Metalness
for the metal), downloaded 2026-09-13.

| Folder | Used for | Source |
|---|---|---|
| `Wood027` | walnut skin (default shell) | https://ambientcg.com/a/Wood027 |
| `Wood095` | ash skin | https://ambientcg.com/a/Wood095 |
| `Wood028` | onyx skin | https://ambientcg.com/a/Wood028 |
| `Metal009` | brushed aluminium frame, lever, button rims | https://ambientcg.com/a/Metal009 |
